# TaskData Mobile

Mobile-only task manager based on the approved mockups. The published version starts with no folders or tasks.

Start the app by double-clicking `Start TaskData Mobile.cmd`. It opens the packaged app directly in Edge; no server or internet connection is required.

Data is stored locally in that browser using localStorage under a Version 2-specific key.

Features: create/delete folders; create unlimited nested tasks; edit task title and state; delete a task and all descendants; create and delete dated task notes.

Flow: Folder -> Level 1 task -> child tasks -> lowest task detail and notes.
